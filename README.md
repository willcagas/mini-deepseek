# mini-deepseek-v3

A miniature implementation of DeepSeekV3 from scratch including multi-head latent attention (MLA), compressed KV caching, DeepSeekMoE, RoPE, RMSNorm, and SwiGLU.

**Read more here:** https://www.wcagas.com/writings/deepseek-v3-from-scratch \
**Original paper:** https://arxiv.org/abs/2412.19437
